🍔 Food Delivery App – UI/UX Wireframe

A complete low-fidelity wireframe for a food delivery mobile application designed using Figma.

📌 Project Overview

This project focuses on designing the user experience and navigation flow of a food delivery application.

The wireframe includes the main screens and user flows required for browsing restaurants, viewing food items, placing orders, and managing the user account.

🎯 Main Features
User Registration & Login
Home Page
Restaurant Browsing
Food Categories
Food Details
Search
Cart
Order Placement
Order Tracking
User Profile
Settings
Reviews & Ratings
🛠️ Tools Used
Figma
UI/UX Design
Wireframing
User Flow Design
🎨 Design

The project was created as a low-fidelity wireframe to focus on the application's structure, navigation, and user experience before implementing the final visual design.
